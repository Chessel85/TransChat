# TransChat

Screen-reader-friendly text chat for up to 8 people who speak different languages.
Each person reads and writes in their own language; each incoming message is
translated for the reader by Google Translate. Works in any modern browser.

**Use it:** https://chessel85.github.io/TransChat/

## How to chat

1. Open the page in any modern browser (Firefox, Chrome, Edge, Safari).
2. Enter your name and pick your language.
3. One person chooses **Start a new room** and shares the room code (for example `blue tiger 42`) or the invite link.
4. Everyone else enters the code and chooses **Join room**. Anyone can leave; the room stays open until the last person leaves.

Keyboard shortcuts are listed on the chat screen under "Keyboard shortcuts".

See [design.md](design.md) for the full design.
