# TransChat

Screen-reader-friendly text chat for two people who speak different languages.
Each person reads and writes in their own language; messages are translated on
the reader's own computer by the browser's built-in translator.

**Use it:** https://chessel85.github.io/TransChat/

## How to chat

1. Open the page in **Google Chrome (version 138 or later) on a desktop computer**.
2. Enter your name and pick your language.
3. One person chooses **Start a new room** and shares the room code (for example `blue tiger 42`) or the invite link.
4. The other person enters the code and chooses **Join room**.
5. The first time a language pair is used, Chrome downloads a translation pack. Press any key in the message box (or the Download button) to start it.

Keyboard shortcuts are listed on the chat screen under "Keyboard shortcuts".
